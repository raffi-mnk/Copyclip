# Copyclip

A small, local macOS clipboard history app. It lives in the menu bar, saves clipboard data between launches, and restores all available pasteboard types when a clip is selected. The menu has ⌘0–⌘9 shortcuts and a configurable clip count. **Clips Management…** opens a searchable window where you can inspect, copy, pin, rename, edit text, and delete clips. Search also finds source app names and bundle IDs.

## Build

Requires macOS 13 or later and Xcode command line tools.

```sh
./Scripts/build-app.sh
open dist/Copyclip.app
```

You can also open `Package.swift` in Xcode for development. The build script makes an optimized universal app (Apple silicon and Intel) at `dist/Copyclip.app`, with its debug symbols in `dist/Copyclip.app.dSYM` for reading crash reports. Copy the app to `/Applications` if you want to enable **Launch Copyclip at login** in Preferences.

## Distribute

```sh
./Scripts/build-dmg.sh
```

This builds the app and packages it as `dist/Copyclip-<version>.dmg`. The version comes from `CFBundleShortVersionString` in `Resources/Info.plist`. The disk image window shows how to install Copyclip and how to open it the first time, and includes `Read Me First.txt` with the same steps. The window background is drawn by `Scripts/dmg-background.swift`. Arranging the window needs permission for your terminal to control Finder; without it the disk image is still built, with a warning.

Copyclip is signed ad hoc, not with an Apple Developer ID, so macOS blocks its first launch. Users allow it once in **System Settings › Privacy & Security › Open Anyway**.

History is stored in `~/Library/Application Support/Copyclip/HistoryIndex.plist` and the adjacent `Clips` folder. Each clip has a small `.meta.plist` file with its preview, source app, and pin state, which stays in memory, and a `.plist` file with its clipboard data, which is read only when the clip is restored or previewed. Clips saved by earlier versions are converted on first launch. Existing `History.plist` data is migrated automatically. The retention limit, menu count, and ignored apps are set in **Preferences…**. Pinned clips always appear at the top of the menu and are protected from retention cleanup, even if that exceeds a selected limit. Lowering the retention limit removes the oldest unpinned clips immediately. Editing a clip saves plain text and removes that clip's previous formatting; renaming changes only its label.

**Private Mode** in the menu pauses recording. Its state persists across restarts, and copies made while paused are skipped when recording resumes. Clipboard monitoring checks only the pasteboard change count twice a second, uses timer tolerance to reduce wakeups, and stops completely during Private Mode. Clip files are saved individually on a background utility queue to avoid rewriting the entire history after each copy.

Copyclip records new copies while it is running; enable launch at login to start recording after a restart. Copyclip does not send clipboard content anywhere. Clipboard items marked by their source app as concealed, transient, or autogenerated are skipped. File promises and legacy `CorePasteboardFlavorType` formats are not saved, TIFF copies of images that also come as PNG are dropped, and any single format larger than 32 MB is skipped.

Ignored apps are identified by the app in the foreground when Copyclip detects the clipboard change. Copies made by background automation may not have a reliable source app.

The persistence check can be run with:

```sh
swiftc Sources/Copyclip/ClipboardStore.swift Tests/ClipboardStoreTests.swift -o /tmp/CopyclipStoreTests
/tmp/CopyclipStoreTests
```
