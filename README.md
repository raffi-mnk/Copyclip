# Copyclip

A small, local macOS clipboard history app. It lives in the menu bar, saves clipboard data between launches, and restores all available pasteboard types when a clip is selected. The menu shows the latest 20 clips with ⌘0–⌘9 shortcuts. Older clips are available in a searchable history window.

## Build

Requires macOS 13 or later and Xcode command line tools.

```sh
./Scripts/build-app.sh
open dist/Copyclip.app
```

You can also open `Package.swift` in Xcode for development. The distributable app is `dist/Copyclip.app`. Copy it to `/Applications` if you want to enable **Launch Copyclip at login** in Preferences.

History is stored in `~/Library/Application Support/Copyclip/History.plist`. It grows until **Delete All History…** is selected. Copyclip records new copies while it is running; enable launch at login to start recording after a restart. Copyclip does not send clipboard content anywhere. Clipboard items marked by their source app as concealed, transient, or autogenerated are skipped.
