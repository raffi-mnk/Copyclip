# Changelog

## 1.3.0

- **Automatic updates.** Copyclip can check for new versions and install them for you. Choose in Preferences.
- Much lower memory use: clip contents stay on disk until you paste or preview them.
- Clipboard formats that can't be pasted again later, and single items over 32 MB, are no longer saved.
- New defaults for new installs: 15 clips in the menu and 100 kept in history.
- Runs natively on Intel Macs as well as Apple silicon.
- A new installer disk image with first-launch instructions.
